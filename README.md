# Job Application Tracker Frontend

React + Vite frontend for a Job Application Tracker app.

## Features

- View job applications
- Create new job applications
- Delete job applications
- Connects to a Spring Boot REST API
- Displays application status, date applied, notes, job link, and interview count

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Spring Boot API backend
- PostgreSQL database

## Running the App

```bash
npm install
npm run dev
